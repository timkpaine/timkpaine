polars-io-tools

Inspect the query and push filters down to the database


import polars as pl
from polars_io_tools import scan_db

orders = scan_db("SELECT * FROM orders", "DSN=warehouse")
result = (
    orders.piot.debug()  # Inspect requested filters and columns
    .filter(pl.col("region") == "EU")  # Push to SQL WHERE
    .piot.filter_no_pushdown(pl.col("amount") > 100)
    .select("id", "amount")
    .collect()
)

Inside the card

Heterogenous execution

polars GPU engine
  • The whole plan runs on the GPU
  • Anything unsupported: the whole plan falls back to CPU
  • Works because the GPU covers almost every operator
scanfiltersortagg
dau
  • Each operator maps to a hardware tile, or stays on the CPU with a stated reason
  • The card runs the part it can carry
  • Rows can be split between card and CPU, which run at the same time
scanfiltersortagg

the card takes what it can, the CPU the rest

Selective and collaborative
